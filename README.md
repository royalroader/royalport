# 로얄포트 · RoyalPort

Windows용 멀티마켓 이미지 업로더의 다운로드 및 자동 업데이트 전용 저장소입니다.

## 다운로드

[최신 버전 다운로드](https://github.com/royalroader/royalport/releases/latest)에서 **RoyalPort.zip**을 받아 폴더 전체를 압축 해제한 뒤 **RoyalPort.exe**를 실행하세요.

처음 실행할 때 사용할 마켓과 계정을 직접 등록합니다. 배포 파일에는 개인 계정, 비밀번호, 로그인 세션, 이미지 경로가 포함되지 않습니다. ESM 업로드에는 Microsoft Edge가 필요합니다.

프로그램은 실행할 때 새 정식 버전을 확인하고 업로드 작업이 끝난 뒤 업데이트합니다. 원본 애플리케이션 소스는 이 저장소에 공개하지 않습니다.
